# Laden mobile demo — publishing package

This folder contains only the standalone Thiên Sơn customer app demo and admin prototype for public static hosting. It excludes customer discovery notes and the rest of the Laden workspace.

Published customer demo:
- Mobile app: https://sadnguyen2107.github.io/laden-thienson-mobile-demo/
- Admin dashboard: https://sadnguyen2107.github.io/laden-thienson-mobile-demo/admin-dashboard.html

To refresh the deployable page after editing the prototype, copy `../prototype/index.html` to this folder as `index.html`.

This is a concept demo with illustrative product details. Open the app and admin in the same browser to try the local product publishing and order-status flow. Changes remain in that browser only; forms do not transmit customer data, create real orders, or update the hosted catalog for other visitors.

The catalog includes a model/engine-code filter. Suggested values and product matches are illustrative until Thiên Sơn confirms its model-to-part compatibility data.
