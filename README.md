# Laden mobile demo — publishing package

This folder contains only the standalone Thiên Sơn mobile commerce prototype for public static hosting. It intentionally excludes customer discovery notes and the rest of the Laden workspace.

To refresh the deployable page after editing the prototype, copy `../prototype/index.html` to this folder as `index.html`.

This is a concept demo with illustrative product details. Its form is local-only and does not place real orders or collect data.
